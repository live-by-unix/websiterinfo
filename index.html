A different approach

Real processes.
Real isolation.

Workers aren't just background tasks. They're independent programs that communicate through a purpose-built IPC layer.

Designed for distributed work.

Your application host coordinates dedicated workers without sharing their memory. Each process can be supervised, restarted, monitored, and scaled independently.

  • ✓ Separate OS process and memory space per worker
  • ✓ Correlation IDs for request/response messages
  • ✓ Bounded queues for backpressure
  • ✓ Timeouts and cancellation support
  • ✓ Supervision with exponential backoff and restart limits
  • ✓ Unix domain sockets and Windows named pipes

Clean C# API

Start with a few lines.

Define routes in C#, keep pages in HTML, and let Websiter handle the plumbing.

Program.cs
using Websiter;

var app = WebsiterApplication.Create(args);

app.MapGet("/", ctx =>
    ctx.Response.WriteAsync("Hello Websiter!"));

app.MapGet("/api/status", ctx =>
    ctx.WriteJsonAsync(new { status = "online", framework = "Websiter" }));

app.MapGet("/users/{id}", ctx =>
    ctx.WriteJsonAsync(new { id = ctx.Param<int>("id") }));

return await app.RunAsync();
